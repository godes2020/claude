# AuraSkills 2.4.0 + анимированные меню (CraftEngine, русский)

Готовые файлы лежат в `auraskills-upload.zip`. Внутри та же структура, что на сервере:

```
plugins/
├── AuraSkills-2.4.0.jar
├── AuraSkills/
│   ├── config.yml              язык по умолчанию: ru
│   ├── menus/*.yml             меню из пака, переведены на item_model + шрифт
│   └── messages/
│       ├── messages_ru.yml     полный перевод (776 строк)
│       └── global.yml          экшн-бар: «+5 опыта · Фермерство»
└── CraftEngine/resources/auraskills/
    ├── pack.yml
    └── resourcepack/assets/spectra_aurelium_skills/   текстуры, модели, шрифт gui
```

## Установка через панель

1. **Files** → загрузить `auraskills-upload.zip` в корень сервера → **Unarchive**.
   Если папки `plugins/AuraSkills` ещё не было, ничего не перезапишется.
2. В консоли: `ce reload all`. CraftEngine пересоберёт ресурспак.
3. Перезапустить сервер (`restart`): новый плагин подхватывается при старте.
4. Проверить в игре: `/skills`, `/stats`. При входе клиент должен принять обновлённый ресурспак.

Если что-то поменяли в меню или сообщениях: `/skills reload`.

## Что сделано

- Пак был под ItemsAdder/Oraxen (`CustomModelData`, `%img_...%`). На 26.1 CustomModelData
  в старом виде не работает, поэтому:
  - иконки → компонент `item_model: spectra_aurelium_skills:<имя>` (как в кошельке);
  - фоны меню и полоска опыта → шрифт `spectra_aurelium_skills:gui` (`<font:...>` в заголовках);
  - отступы `:offset_N:` → символы `space`-провайдера того же шрифта;
  - голова игрока в «Характеристиках» → `minecraft:special` + `player_head`, `oversized_in_gui`.
- Надписи на деревянных плашках перерисованы на русский тем же пиксельным стилем:
  НАВЫКИ, СПОСОБНОСТИ, УРОВНИ, ХАРАКТЕРИСТИКИ, ТОП ИГРОКОВ, ИСТОЧНИКИ ОПЫТА.
- `%tinify_...%` (маленькие латинские буквы) убран: на кириллице он не работает.
  Расширение `Expansion-tinify.jar` ставить не нужно.
- В меню добавлено то, что появилось в 2.4.0 после выхода пака: `job_cooldown`, форматы чисел,
  меню `stat_info.yml` (стандартное).
- Стандартный `messages_ru.yml` из плагина был неполным (134 строки на английском) и с ошибками,
  поэтому перевод сделан заново и одинаковыми терминами везде.

## Прокачка

Система опыта (`xp_requirements.yml`, `sources/`) **не менялась**. Готового бесплатного
и проверенного баланса лучше стандартного найти не удалось, есть только платные конфиги.
Стандарт: `100 * (уровень - 2)^2 + 100` опыта на каждый следующий уровень.

## Пересборка

```
pip install pillow ruamel.yaml
python3 build.py animated_aurelium_skills_0.1.zip AuraSkills-2.4.0.jar
```

Перевод правится в `translations.py`, надписи на плашках — в `TITLES` в `build.py`.
